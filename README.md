# Emart · Prototipo de tienda web

Prototipo navegable de la tienda online de Emart (accesorios y gadgets, Bolivia).
Sitio estático: un solo `index.html`, sin compilación.

> Contenido de ejemplo: productos, precios, fotos, reseñas y datos de contacto son provisionales.

## Publicar en Netlify
1. En Netlify: **Add new site → Import an existing project → GitHub** y elegir este repositorio.
2. Build command: *(vacío)* · Publish directory: `.`
3. Deploy.
